# Foundation map artwork

Thumbnails from the teacher demonstrations already embedded in the corresponding
lessons. Exact source URLs are recorded in sources.json. Preparation uses the
existing preparation materials reference capture. No generated replacement art.

The shared SketchMap.lessonRows renderer serves both Form and Structure and
Still Life and Texture, retaining the same completedLessons identifiers and
lesson access checks. Artwork remains visible after completion with a separate
checkmark overlay. Unfinished content stays labeled in development.

The main path is Intro → Step 1 → Step 2 → Step 3 → Step 4. Intro completion is
set on the native video ended event, stored in the existing session profile and
in browser storage scoped to the learner identity. Closing early does not mark
complete. Existing lesson progress is preserved and completed packages remain
revisitable. The intro dialog closes when finished, leaving its checked path row.
