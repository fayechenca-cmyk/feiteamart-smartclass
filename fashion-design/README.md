# Fashion Design · 课程接入与教师素材

本课程是现有 `feiteamart-smartclass` 的子目录，使用原生 HTML/CSS/JS，无新框架或构建依赖。

## 文件位置

- 首页 `index.html` 的 Skill 分类：Fashion Design 入口；`?view=skills` 返回 Skill。
- `fashion-design/index.html`：统一课程页面。`#course` 概览、`#lesson` 当前学习阶段、`#paper` 三层纸上练习、`#works` 作品。
- `fashion-design/course-data.js`：六单元框架、第一课的全部演示比例、路径、顺序、提示、容差和声音参数。
- `core/fashion-tracing.js`：可复用 SVG 比例框架、Pointer Events 手绘、动画、轨迹判断和 PNG 导出。
- `core/fashion-tracing.css`：沿用现有课程 Montserrat/Open Sans、浅紫—浅蓝—青色背景、白色课件容器、青色主按钮与圆角卡片。学生界面、逐笔讲解、反馈和纸上练习均为英文。
- `fashion-design/app.js`：学习流程、进度、作品、纸上练习、现有上传接口适配。
- `fashion-design/lesson-template.json`：教师可填写的下一课模板。它不是可运行课节；null 和空路径必须先填写、审核。
- `fashion-design/assets/`：正式 SVG、示范图、逐笔音频、视频和最终效果图的预留目录。

## 第一课如何转为正式课程

目前所有结构和讲解均为原创交互演示；没有按照片提取坐标，没有宣称是八头身或九头身标准。已查看教师提供的 IMG_9095.HEIC 和 IMG_9096.HEIC；只用于理解构图、结构与教学顺序，未从照片提取精确坐标。

请提供：

1. 确认使用八头身、九头身或其他比例；头顶/下巴、肩、胸、腰、臀、膝、踝、脚跟、脚尖的位置，以及肩宽、胯宽、重心说明。用统一坐标或占画布百分比均可。
2. 一张完整基础站姿线稿，最好是 SVG（含 viewBox）；每一笔独立 path，按起笔到停笔的方向排列。若只有高清平扫图，可按教师确认的结构重新制作矢量线稿，不自动将倾斜照片当标准。
3. 步骤顺序、阶段划分；每笔起点、终点、经过的关节点，哪些是结构线、哪些是人物最终轮廓。
4. 每笔一句讲解、常见错误与友好提醒；阶段回顾的问题；适用年龄。
5. 最终效果图，以及可选的逐笔语音、老师示范视频、使用授权/来源。
6. 纸上练习希望保留哪些辅助线、是否打印结构线，以及最终的教学比例确认。

把以上内容填入模板即可，不必懂 SVG：不确定的内容写“待确认”并附注；我可以先整理成待审核数据。正式发布前需教师确认每条路径、提示和比例。

## 数据约定

所有数据和学生笔画共用 `canvas.width/height` 坐标。SVG 使用 `viewBox`，落点通过 `getScreenCTM().inverse()` 转换，因此页面滚动、CSS 缩放、设备像素比不会要求重新提取坐标。每张画板只画一个人物。下一姿势复用同一引擎，替换 Lesson 数据并注册入口即可。

- `guides` 定义横线；`centerLine` 定义中心线；`points` 定义关节点。
- `steps[].path` 为单笔 SVG path 的 d 属性，支持直线和曲线；将变换预先应用到坐标，避免外层 transform。每笔应连续，不含独立多段跳笔。
- 起止区域的中心自动取 path 的首尾点，`startRegion/endRegion.radius` 可编辑。direction 作为教师说明保留；实际顺序由 path 命令决定。
- `tolerance` 为画布单位，不是设备像素。鼠标、手指和笔分别设置。检查起止区、整体覆盖、离线比例及四个沿途位置的先后顺序，不逐像素打分。
- `animation.duration` 为毫秒，减少动态效果设置下直接显示示范；`sound` 为轻声合成确认音。`audio`、`assets` 是正式音频/图片/SVG/视频的接入位置，本版本没有自动播放这些尚不存在的素材。
- `status`: `demo` 可体验但未批准；`planned` 待开发；`awaiting-teacher` 待教师素材；未来审核后可增加 `ready`。不可仅把未完成课标为 ready，应先完成数据验证和入口接入。
- 修改几何坐标或步骤 ID 后须递增 Course.version，避免旧轨迹被误套到新线稿。

## 进度与上传范围

复用现有 `fei_user_profile` 身份（优先 sessionStorage，其次 localStorage），按 supabaseUserId / studentCode / learnerId / guest 隔离保存。当前 key 为 `fei_fashion_v2:<identity>:<lessonId>`。记录阶段、当前步、三种模式各自的笔画和完成状态、纸上练习勾选。既有 Supabase student_progress 表没有轨迹字段，因此本版本不向该表塞入数据，不覆盖正式课程完成记录。

只在当前浏览器恢复；没有跨设备同步。访客共用该浏览器的 guest 记录。隐私模式/存储配额异常显示“请导出”；退出网站时既有清理逻辑可能移除 fei_* 缓存。保存的作品可以导出成 800×1400 PNG，不强制教学辅助线。纸上照片不放进 localStorage，选择后只在当前页面预览，离开即释放；提交成功会记录提交时间。

纸上照片显式调用现有 `FEISubmissions.submit`（core/submissions.js），沿用网站登录和作品权限。没有登录/网络失败会明确返回错误；不会显示虚假的成功。代码接入已完成，但本地测试没有以真实学生账户向生产上传作品。用户可在已登录正式站点验证上传。

## 测试

启动项目已有静态服务器后打开 `/fashion-design/tests/interaction.html`，点击 Run。测试理想曲线、自然偏差、反向和偏离、当前全部逐笔流程与阶段、撤销重做、刷新、模式隔离、390px/768px 坐标、纸上记录和实际 PNG bytes。该页面使用合成 PointerEvents 验证引擎，临时备份并恢复本机 guest 记录；只在本地开发中运行，不在真实学生会话中运行。

另需用真实鼠标拖动检查输入；iPad/Apple Pencil 硬件压感和真实 Safari 触控体验需在设备上验收。当前笔触为统一线宽，支持 pen 输入，不依赖压感。


## 教师顺序修订 v2

先进入四组定位：头顶/下巴、肩宽、腰宽、臀宽。点击两个标记完成每组定位，然后进入正式描画。`landmarks` 定义这些互动；`groups` 定义教师所说的教学步骤，`steps` 是每一笔或定位活动。因此“圆＋下颌”同属 Step 1，Step 2 就是肩线，不会把下颌或脖子误标成第二个教学步骤。

当前为 14 个教学步骤、36 笔描画和 1 个承重脚踝定位活动。顺序：头部 → 肩线 → 腰线 → 臀线 → 双侧上躯干 → 双侧腰臀 → 重心 → 大腿与膝弧 → 小腿 → 踝与脚 → 颈部圆柱 → 斜肩 → 上臂 → 前臂。腿部“脚”究竟指小腿还是脚掌仍待教师确认，目前按小腿理解；没有将未确认的强透视线稿当成正式标准。

`tip` 是每笔持续显示的教师提示；`overlays` 包括腰臀平行方向与后脑至承重踝的竖直观察线。该竖直关系只用于当前姿势提示，不表述为所有站姿的普遍规律。背景横向比例线与人物倾斜的结构线是不同层。

旧 v1 记录原封保留。作品页的 Earlier demo artwork 可导出旧作品，新版几何不会沿用旧轨迹。`legacy-demo-v1.js` 是原几何存档，不在新版页面加载。

### 后续视频

视频收到后先按 `steps[].id` 配对片段，再填写 `video.src/start/end/poster`。可以直接指向单独剪辑文件，也可以用统一 `teacherVideo.src` 与各步起止秒数；播放器在片段末尾暂停，再播放会回到该片段起点。未提供视频时只显示等待素材说明，没有假播放按钮。教师可提供一段完整连续示范，不必自己先剪碎。

音效改为可配置的双音铃声：`strokeNotes` / `phaseNotes`，每音间距 `noteGap`、衰减 `duration`、音量 `volume`。正确描画和完成定位各有视觉与声音反馈；Test completion sound 可以用一次明确点击激活并试听浏览器音频。
