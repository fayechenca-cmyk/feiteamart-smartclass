# The Sphere · guided preview

Continues Preparation → Cube → Sphere with the same full-screen, self-paced studio. 46 microsteps preserve the original welcome, six light zones, movable light, materials, readiness, all 26 authored analysis checkpoints (including A/B views), all four teacher demonstrations, photo preview, optional finishing video, and closing reflection.

Teacher-video durations are read from Cloudflare HLS manifests. Main demonstrations are segmented at existing authored pause times; every second is retained in order. Optional finishing spans background tone, surrounding values, edge refinement, and final blending; its full footage is retained and can be skipped as a group. Reference images stay beside the video on desktop; phones keep both within the screen. Existing analysis narration is reused; new opening, transitions, encouragement and closing use Ava. One core-shadow explanation is corrected to distinguish the shadow band from a hard outline.

Rewards share `core/guided-reward.js` across Preparation, Cube and Sphere. A lesson completion opens Artchi's modal with fanfare and an incremental colour reveal of the existing Basic Sketch artwork. Counts are unique lesson IDs, drawn from the 11-course foundation path. Existing completed guided-preview courses are imported; repeated completion does not add credit. These are local practice milestones, not official teacher-reviewed badges or account progress. Mute and reduced-motion settings are respected. The standalone reward preview never writes progress.

Validation: node tests/sphere-guided.cjs; node tests/guided-reward.cjs. Browser checks cover first steps, reference rendering, modal, and responsive layouts.
