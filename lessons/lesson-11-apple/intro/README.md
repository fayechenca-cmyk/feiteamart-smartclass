# Meet the apple

Intro film for The Apple (Level 2 · Form in Real Objects), in the same format
as the cylinder intro: ~85-second film, 1280×720, English Ava teacher-style
synthetic narration (edge-TTS en-US-AvaMultilingualNeural, rate +3%),
optional English captions, teacher demonstration clips.

- `poster.jpg` — the teacher's finished apple drawing.
- `scenes.json` — complete narration and timing (8 scenes).
- `captions.vtt` — English captions timed to the narration.
- `voice-0.mp3` … `voice-7.mp3` — per-scene narration audio.

`meet-the-apple.mp4` is rendered from these sources (stills + Stream clips);
rebuild by adapting scripts/render-cylinder-intro.py.
